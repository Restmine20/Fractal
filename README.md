# Приложение для визуализации фракталов

В данном репозитории представлен исходный код настольного приложения для визуализации 
фракталов (множества Мандельброта, множества Жюлиа). Ключевой особенностью является использование
технологии CUDA для параллельных вычислений.

---

## О проекте

Программа совмещает интерфейс на Python и параллельные вычисления на C++/CUDA. Расчет координат и цвета точек фрактала происходит на графическом процессоре (GPU). Это обеспечивает мгновенный рендеринг изображений высокого разрешения при масштабировании.

### Основные возможности
* Визуализация множеств Мандельброта и Жюлиа
* Интерактивный графический интерфейс для изменения различных параметров
* Возможность приближения выделенной области

---

## Структура репозитория

* `main.py` — главный файл и точка входа в приложение
* `fractals.cu` — исходный код C++/CUDA с функциями расчета множеств
* `gpu_initialize.py` — модуль для инициализации видеокарты
* `build_interface.py` — модуль для построения интерфейса
* `global_objects.py` — хранение глобальных переменных
* `utils.py` — вспомогательные функции
* `requirements.txt` — список необходимых библиотек Python
* `fractals_bin/` — директория для скомпилированных бинарных файлов
* `icon.ico` — иконка приложения.

---

## Требования к системе

Для запуска приложения необходимы:
1. **Python 3.10+**
2. Дискретная видеокарта NVIDIA с актуальной версией драйвера

---

## Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Restmine20/Fractal
   cd Fractal
   ```

2. Установите зависимости Python:
   ```bash
   pip install -r requirements.txt
   ```
   
3. Запуск:
   ```bash
   python main.py
   ```
